Radar Legajo

Publishing tool for the Legajo Antiguo YouTube channel

Radar Legajo is a private desktop tool used only by the owner of the Legajo Antiguo channel. It runs on the owner's own computer and publishes the channel's history documentaries through the YouTube Data API.

What it does

  • Uploads videos to the owner's channel.
  • Sets each video's thumbnail, title, description and translations.
  • Updates the channel's banner and description.
  • Lists the channel's recent uploads, so the owner can confirm each one.

It is not offered to the public. No other person's Google account or YouTube channel is used.
