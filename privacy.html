Privacy Policy

Radar Legajo. Last updated: November 6, 2026

Radar Legajo is a private desktop tool used only by the owner of the Legajo Antiguo YouTube channel. This policy explains what happens to Google and YouTube data when the owner signs in.

YouTube API Services

Radar Legajo uses YouTube API Services. By using it, you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data the tool accesses

After the owner signs in with Google, the tool can access the owner's own YouTube channel through these permissions:

  • Upload videos (youtube.upload): to send new videos to the channel.
  • Manage the YouTube account (youtube): to set thumbnails, titles, descriptions, translations and the channel banner, and to read the list of recent uploads.

The tool does not read Gmail, contacts, Drive or any other Google data, and it does not access other people's accounts.

How data is used

The data is used only to publish and confirm videos on the owner's channel. It is not used for advertising or profiling.

Storage and retention

  • Sign-in tokens are stored only on the owner's computer, outside any public folder. They remain there until the owner revokes access or deletes them.
  • After a video is published, its working files are deleted from that computer. A local history keeps the video's title, ID, publication dates and script.
  • The tool has no server or database of its own, so no Google or YouTube data is stored by the tool anywhere else.

Sharing

Google and YouTube data is not sold or shared with third parties. It is sent only to Google's own services, in order to perform the actions listed above.

Revoking access

Access can be removed at any time on the Google Account permissions page.

This website

This website sets no cookies and has no analytics. It is hosted on GitHub Pages, and GitHub may process visitors' technical data, such as IP addresses, as described in the GitHub Privacy Statement.

Changes and contact

Changes to this policy are published on this page, with a new date at the top. Questions can be sent through the project's issue page.
